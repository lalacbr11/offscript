## Submitted description

Inspired by date nights with my wife, OffScript helps couples break routine with 36 date ideas matched to both partners' moods, energy, budget, time, and exclusions. Using Figma Make, I expanded the first draft, added activity filters and saved plans, and refined navigation. Manual desktop and iPhone testing uncovered issues with reopening plans, silent repeat suggestions, and partner-answer privacy, which I fixed and retested.
